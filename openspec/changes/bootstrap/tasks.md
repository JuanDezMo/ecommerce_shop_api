# Tasks

> Convención: los tests que no necesitan base de datos terminan en `*Test` y corren con `./gradlew test`. Los que usan Testcontainers terminan en `*IT` y corren con `./gradlew integrationTest`. `./gradlew check` corre ambos (design D10). Cada tarea sigue el ciclo test que falla → código mínimo → refactor → commit.
